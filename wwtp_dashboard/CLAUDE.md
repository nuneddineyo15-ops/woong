# 프로젝트 컨텍스트

폐수처리 공정 품질 관제 대시보드(Streamlit). 상세 배경, 설비 구조, 감지 규칙, 화면 설계 이유는 아래 문서 참고.

@HANDOFF.md

## 항상 지킬 것

- HANDOFF.md의 5번(감지 규칙)과 6번(설계 결정)은 **사용자 허락 없이 바꾸지 말 것.** 바꿔야 하면 이유와 영향을 먼저 설명.
- 데이터 소스(DB 종류, 접속 방법), 센서 태그 이름 규칙, 실제 규격값은 **추측하지 말고 모르면 질문.**
- 작업 순서: ① 데이터 연결 → ② 규격/설정 교체 → ③ 오탐 점검 → ④ 화면 미세 조정. 단계마다 동작 확인 후 다음으로.
- 감지 로직을 건드리면 **이상 없는 평소 구간에서 경고가 몇 개 걸리는지 먼저 확인.**
- 데모 모드(`ANOMALIES` 및 난수 생성)는 삭제하지 말고 남겨둘 것. 테스트용.
- 사내 데이터를 외부로 보내는 코드(외부 API, CDN, 텔레메트리)를 넣지 말 것.
- 구조는 설정 기반 유지. 건물/공정/계열/센서 수를 하드코딩하지 말 것.
- **디자인 지시서(HANDOFF.md 6-0)를 기준으로 화면을 만들 것.** 공정 흐름 중심, 3초 안에 이상 공정 인지, 신호등 노드+글로우, 차트 이상점(큰 붉은 점·붉은 음영·경고 문구), 상단 이상점 요약 바(누르면 연동), 영향 화살표.
- **템플릿 같은 대시보드 금지.** 카드·KPI 타일을 네모칸으로 나열하는 흔한 구조, 둥근 모서리+그림자 카드, 그라데이션, 이모지 아이콘 남발, 똑같은 너비의 그리드 배치를 쓰지 말 것. 지향: 현장 HMI·계장 도면 스타일 — 선·글자 크기·공정 흐름으로 구분, 정상은 조용하게(작고 회색), 이상만 강하게(색 채움). (2026-11-04 사용자 지시)
